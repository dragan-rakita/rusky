# Russian A1 Grammar (Lessons 1–15)

Stress marks (´) show the stressed syllable. Stress moves around in Russian, so always learn it with the word.

## 1. Pronunciation and spelling

| Rule | Example |
| --- | --- |
| Unstressed **о** sounds like "a" | хорошо́ = "harashó", спаси́бо = "spasíba" |
| **е** = "je", **э** = plain "e" | э́то (never "ето") |
| **ы** is a hard "i", a separate letter from и | мы (never "ми") |
| **ь** has no sound; it softens the consonant before it | пять, фильм, пятьдеся́т |
| **я** already contains the "a" sound | я (never "яа") |
| Silent letters | здра́вствуйте = "zdrástvujte", сего́дня = "sivódnja" |
| Days of the week are lowercase | понеде́льник, суббо́та |
| After **к, г, х, ж, ш, щ, ч** write **и**, never ы | ру́сский, хоро́шие |

## 2. No "to be" in the present tense

Serbian *Ja sam student* = **Я студе́нт.** The verb is simply left out.

In writing, a dash often replaces Serbian *je*: Москва́ — большо́й го́род.

## 3. Noun gender

Works like Serbian.

| Gender | Ending | Example |
| --- | --- | --- |
| masculine | consonant | дом, брат, телефо́н |
| feminine | ‑а / ‑я | кни́га, маши́на, семья́ |
| neuter | ‑о / ‑е | окно́, мо́ре |

Exception: **ко́фе** is masculine and never changes form.

## 4. Personal pronouns

| Russian | Serbian | English |
| --- | --- | --- |
| я | ja | I |
| ты | ti | you (informal) |
| он / она́ / оно́ | on / ona / ono | he / she / it |
| мы | mi | we |
| вы | vi | you (formal or plural) |
| они́ | oni | they |

## 5. Present tense

**Rule:** ‑ть appears only in the infinitive. Conjugated forms never end in ь, except ‑шь (ты).

| | Group 1: ‑ать (знать) | Group 2: ‑ить / ‑еть (говори́ть) |
| --- | --- | --- |
| я | зна**ю** | говор**ю́** |
| ты | зна**ешь** | говор**и́шь** |
| он / она́ | зна**ет** | говор**и́т** |
| мы | зна**ем** | говор**и́м** |
| вы | зна**ете** | говор**и́те** |
| они́ | зна**ют** | говор**я́т** |

- **Group 1:** рабо́тать, знать, чита́ть, понима́ть, де́лать, игра́ть
- **Group 2:** говори́ть, смотре́ть, звони́ть, по́мнить, люби́ть, ви́деть

### Irregular verbs

| | жить (live) | хоте́ть (want) | есть (eat) |
| --- | --- | --- | --- |
| я | живу́ | хочу́ | ем |
| ты | живёшь | хо́чешь | ешь |
| он / она́ | живёт | хо́чет | ест |
| мы | живём | хоти́м | еди́м |
| вы | живёте | хоти́те | еди́те |
| они́ | живу́т | хотя́т | едя́т |

Small changes in the я form: люби́ть → люб**л**ю́, ви́деть → ви́**ж**у.

Хоте́ть takes an infinitive or the accusative: Я хочу́ спать. · Я хочу́ ко́фе.

## 6. Past tense

Take the **infinitive**, remove ‑ть, and add an ending for gender or number (like Serbian *radio / radila*).

| Who | Ending | рабо́тать | смотре́ть | жить |
| --- | --- | --- | --- | --- |
| he, or I/you (male) | ‑л | рабо́тал | смотре́л | жил |
| she, or I/you (female) | ‑ла | рабо́тала | смотре́ла | жила́ |
| it | ‑ло | рабо́тало | смотре́ло | жи́ло |
| we, you (pl.), they | ‑ли | рабо́тали | смотре́ли | жи́ли |

Always start from the infinitive: смотре́-ть → смотре́ли (not "смотрили").

## 7. "I have"

Russian says "at me there is": **у + person (genitive) + есть + thing (nominative)**.

| Russian | English |
| --- | --- |
| У меня́ есть маши́на. | I have a car. |
| У тебя́ есть брат? | Do you have a brother? |
| У него́ / у неё есть ... | He / she has ... |
| У нас / у вас / у них есть ... | We / you / they have ... |
| У меня́ нет вре́мени. | I don't have time. (нет + genitive) |

With a noun, use the genitive, like Serbian *kod mog brata*:

| Nominative | After у |
| --- | --- |
| мой брат | у моего́ бра́та |
| мой оте́ц | у моего́ отца́ (е drops out) |
| моя́ сестра́ | у мое́й сестры́ |

## 8. Cases

### Prepositional (location: где?)

Works like the Serbian locative. Used after **в** (in) and **на** (on/at).

| Ending | Change | Example |
| --- | --- | --- |
| consonant | + е | дом → в до́ме |
| ‑а / ‑я | → е | Москва́ → в Москве́ |
| ‑о | → е | окно́ → на окне́ |

- Я живу́ в Ба́ня-Луке. (in) vs Я из Ба́ня-Луки. (from: из + genitive)
- Exception: Я до́ма. = I'm at home.

### Accusative (direct object)

Works like Serbian *čitam knjigu*.

| Word type | Change | Example |
| --- | --- | --- |
| feminine ‑а | → у | Я чита́ю кни́гу. |
| feminine ‑я | → ю | Вы зна́ете Ка́тю? |
| masculine thing | no change | Мы смо́трим фильм. |
| masculine person or animal | → а | Она́ лю́бит бра́та. |
| neuter | no change | Я люблю́ мо́ре. |

## 9. Possessives

Agree with the noun's gender, like Serbian *moj / moja / moje / moji*.

| | my | your (informal) |
| --- | --- | --- |
| masculine | мой | твой |
| feminine | моя́ | твоя́ |
| neuter | моё | твоё |
| plural | мои́ | твои́ |

## 10. Adjectives

Agree with the noun's gender and number.

| | Ending | Example |
| --- | --- | --- |
| masculine | ‑ый (default) / ‑ий (after к г х ж ш щ ч) / ‑ой (stressed) | но́вый дом, ру́сский фильм, большо́й го́род |
| feminine | ‑ая / ‑яя | но́вая маши́на |
| neuter | ‑ое / ‑ее | но́вое окно́ |
| plural | ‑ые / ‑ие | но́вые кни́ги, хоро́шие кни́ги |

Use ‑ий only after к, г, х, ж, ш, щ, ч. After н and в it is always ‑ый: но́вый, краси́вый.

## 11. Numbers and counting

- **0–10:** ноль, оди́н, два, три, четы́ре, пять, шесть, семь, во́семь, де́вять, де́сять
- **11–19:** add ‑надцать (Serbian ‑naest): оди́ннадцать, двена́дцать … девятна́дцать
- **Tens:** два́дцать, три́дцать, **со́рок**, пятьдеся́т, шестьдеся́т, се́мьдесят, во́семьдесят, **девяно́сто**, сто
- **Compounds** have no "i": 57 = пятьдеся́т семь

### Noun form after a number

| Number | Years | Hours | Minutes |
| --- | --- | --- | --- |
| 1 | год | час | мину́та |
| 2, 3, 4 | го́да | часа́ | мину́ты |
| 5–20 | лет | часо́в | мину́т |

- Мне три́дцать два го́да. = I'm 32.
- Сейча́с пять часо́в два́дцать мину́т. = It's 5:20.

## 12. Time and days

- **What time is it?** Кото́рый час? / Ско́лько вре́мени?
- **At what time?** Во ско́лько? (во, not в)
- **At seven in the evening:** в семь часо́в ве́чера
- **Parts of the day:** у́тром, днём, ве́чером, но́чью
- **On a day:** в + accusative: в понеде́льник, в сре́ду, в пя́тницу, в суббо́ту, в воскресе́нье

## 13. Questions

| Russian | English |
| --- | --- |
| Что э́то? | What is this? |
| Где? | Where? |
| Ско́лько? | How much / how many? |
| Во ско́лько? | At what time? |
| Как дела́? | How are you? |

Yes/no questions use the same word order as statements, with rising intonation: Ты понима́ешь?

## 14. Common mistakes

| Wrong | Right | Why |
| --- | --- | --- |
| ето | э́то | е = "je", use э |
| ми | мы | ы is a separate letter |
| гледать | смотре́ть | Serbian word |
| радит | рабо́тает | Serbian word |
| кафу | ко́фе | ко́фе never changes |
| работаеть, говорять | рабо́тает, говоря́т | no ь in conjugated forms |
| она говорить | она говори́т | conjugate after a pronoun |
| смотрють | смо́трят | group 2: они́ → ‑ят |
| смотрили | смотре́ли | past tense comes from the infinitive |
| живют | живу́т | жить is irregular |
| новий, красивий | но́вый, краси́вый | ‑ий only after к г х ж ш щ ч |
| брать (brother) | брат | брать = to take |
| у моего отец | у моего́ отца́ | genitive after у |
| воскресение | воскресе́нье | воскресе́ние = resurrection |

## 15. False friends (Russian / Serbian)

| Russian | Means | Not |
| --- | --- | --- |
| неде́ля | week | nedelja (Sunday = воскресе́нье) |
| фами́лия | surname | familija (family = семья́) |
| живо́т | belly | život |
| любить | to love | ljubiti (to kiss) |
| столи́ца | capital city | stolica |
| е́хать (ты е́дешь) | to go by vehicle | jesti (to eat = есть, ты ешь) |
